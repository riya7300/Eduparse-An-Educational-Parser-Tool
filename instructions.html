Instructions

How it Works

1. Enter Your Grammar

Use the format E -> E + T | T. Each production should be on a new line. Use ε for epsilon productions.

2. Choose a Parser

Select between LR(0), SLR(1), CLR(1), or LALR(1) from the dropdown menu depending on your needs.

3. Provide a Test String

Enter a space-separated string (e.g., id + id) to see how the parser processes it step-by-step.

4. Analyze Results

Click "Generate" to see the Augmented Grammar, First/Follow sets, Canonical Items, Parsing Table, and the final Parse Tree.
